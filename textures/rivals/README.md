# Rivals texture-pack workspace

This folder is a workspace for original or properly licensed texture assets. It does not install textures into the live Rivals client and must not be used to replace protected game assets.

Suggested organization:
- ui/ — original HUD mockups and icons
- materials/ — original tileable material textures
- previews/ — screenshots of your own permitted test scene
- manifest.json — asset names, dimensions, creator, and license

Do not redistribute Roblox/Rivals assets unless you have permission.
